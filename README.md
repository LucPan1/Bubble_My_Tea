# 🧋 My_Bubble_Tea

My_Bubble_Tea est une application web de e-commerce développé avec le framework Laravel, dédié à la vente de bubble tea

## 🛠️ Technologies utilisées

<ul>
  <li><strong>Backend:</strong> Laravel </li>
  <li><strong>Frontend:</strong> Blade / HTML / CSS / JavaScript </li>
  <li><strong>Base de données:</strong> MySQL </li>
  <li><strong>Outils:</strong> Composer, Git</li>
</ul>
