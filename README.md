# 🧋 My Bubble Tea

My Bubble Tea est une application web de e-commerce développé avec le framework Laravel, dédié à la vente de bubble tea
utilisant un système CRUD complet pour la gestion des produits, utilisateurs.

## 🛠️ Technologies utilisées

<ul>
  <li><strong>Backend:</strong> Laravel </li>
  <li><strong>Frontend:</strong> Blade / HTML / CSS / JavaScript </li>
  <li><strong>Base de données:</strong> MySQL </li>
  <li><strong>Outils:</strong> Composer, Git</li>
</ul>

## ⚙️ Utilisation du CRUD

Le projet repose fortement sur le principe du CRUD, qui permet de gérer les données de l’application.

🔹 Côté administrateur

Le CRUD est utilisé pour gérer les éléments principaux du site:

## 🧋 Produits (bubble tea)

- Create : ajouter un nouveau produit
- Read : afficher la liste des produits
- Update : modifier un produit existant
- Delete : supprimer un produit

## 👤 Utilisateurs

🔹 Côté utilisateur

- Create : créer un compte, passer une commande
- Read : consulter les produits et ses commandes
- Update : modifier ses informations personnelles

## 🧱 Architecture technique

Le projet suit l’architecture MVC de Laravel :

- Modèle : gestion des données (produits, commandes…)
- Vue : interface utilisateur avec Blade
- Contrôleur : logique métier (traitement des actions CRUD)
